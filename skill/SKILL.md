# 考试复习资料生成

## 触发条件

用户提到以下任意一种需求时调用：
- "我要复习..."
- "帮我整理...的考试资料"
- "生成...的复习材料"
- "期末考试..."
- "期中复习..."
- 用户要求"根据课件内容生成复习资料"时

## 执行规则

1. **一次生成全部** — 按顺序完成：复习范围确认 → 复习脉络 → 逐课讲解 → Cheat Sheet
2. **逐课讲解语言模式**：默认中文为主，术语保留英文。用户明确要求"全英文讲解"或"两种语言都要"时，切换为全英文模式——用英文"说人话"，叙述流畅，每章开头有「本章概览」。无论哪种模式，必须覆盖本章所有知识点，不留遗漏
3. **术语参考原则**：如果用户提供的课程资料是英文版，术语用词必须完全参考课程资料中的原文，不自行替换或翻译
4. **Cheat Sheet**（全英文）：带入考场的资料。不需要例子/引入，只收知识点、定义、公式、条件、推导步骤。结构清晰便于查找。必须包含所有在逐课讲解中出现过的知识点，不遗漏
5. **知识点不独立成文件** — 以 📌 内嵌卡片附属于课节，不单独建知识点卡片目录
6. **不生成独立术语对照表** — 术语随课处理，中英文解释在课节中完成
7. **首遍只生成复习内容** — 考试/练习题仅在用户明确要求后追加
8. **不设反馈 callout** — 课节末尾只有快速检查问题，不强制学习反馈入口

## 工作流程

1. 确认复习范围：
   - 覆盖哪些材料、哪些章节/lecture
   - 考试日期与紧迫程度
   - 是否允许携带 Cheat Sheet
   - **用户是否有指定的"不重要的部分"或"重要的部分"**：如某些章节、case study、代码、作业中的某些题等。记录到 `课程材料记录.md` 的"排除范围"或"备注"中
   - **逐课讲解语言偏好**：默认中文为主（术语保留英文）。用户明确要求"全英文讲解"或"两种语言都要"时，切换为全英文模式。全英文模式同样用"说人话"方式讲解，只是叙述语言变为英文
2. 创建输出目录：`{课程名}-{日期}`，日期格式为 `YYYYMMDDHHMM`
3. 生成 `课程材料记录.md`：记录所有输入材料的范围、内容摘要、来源，以及用户指定的排除/重点范围
4. 生成 `复习脉络.md`：按复习逻辑排序，标注难度、核心知识点、前置要求。标注用户指定的重点/非重点
5. 生成 `复习首页.md`：标注两步学习顺序（逐课讲解 → Cheat Sheet）
6. 逐课生成 `第01课-{主题}.md` 至 `第N课-{主题}.md`：
   - **默认中文为主**：中文叙述，术语保留英文，每章开头有「本章概览」
   - **全英文模式（用户明确要求时）**：英文叙述，用英文"说人话"，术语完全参考课程资料原文，每章开头有「本章概览」
   - **必须包含本章所有知识点**，确保材料中涉及的每一个概念、公式、定义、条件、推论、特例都在讲解中覆盖，不遗漏
   - 对于用户指定为"不重要"的部分，可以简要提及核心知识点（保留知识点本身），但不需要展开推导或详细例子
7. （可选）生成 `Cheat Sheet.md`：全英文，包含所有知识点，结构清晰，便于查找和删减。不包含例子或引入性文字
8. （可选）用户确认 Cheat Sheet 内容后，要求"转成 LaTeX"或"输出 PDF"时：
   - 定位输出目录中的 `Cheat Sheet.md`
   - 调用 `md2tex.py` 将其转换为单文件 `.tex` 格式（详见 tools/md2pdf 下的 README）
   - 生成的 `.tex` 文件放入同一输出目录
   - 告知用户：上传 Overleaf，编译器选 XeLaTeX，直接编译
9. 用户明确要求后，结合课程资料（重点参考作业考察要点），参考你的经验中相关知识点的常见考察方式，追加考试或练习题

## 课程内容模板

每课必须包含以下部分，按顺序排列：

1. **本章概览** — 告诉用户这一章会讲什么、为什么重要、和前后章的关系。如用户指定了某些内容不重要，在此说明
2. **来源依据** — 标注来源文件、位置、使用方式（原文/解释/AI补充）。如果某部分内容被用户指定为不重要，标注"用户指定为次要内容"
3. **本课目标** — 学完应能理解什么、做到什么
4. **知识点清单** — 用 Obsidian 双链列出本课所有知识点
5. **核心内容讲解** — 包含本章所有知识点和细节。确保材料中涉及的每一个概念、公式、定义、条件、推论、特例都在讲解中覆盖，不遗漏。所有讲解生成完成后要再次跟原课程资料对比，确认无遗漏知识点。对于用户指定为不重要的部分，保留知识点本身，简要提及，不展开推导或例子。若涉及自行额外生成的补充知识点，请明确标注为“AI补充”。
6. **内嵌知识点卡片** — 每个核心知识点用 📌 卡片格式呈现（不生成独立文件）
7. **快速检查** — 1-3 个问题检查理解，不含反馈 callout

可选部分根据内容自然加入：生活类比、图解、考试题型提示、练习题。

### 内嵌知识点卡片格式

```markdown
### 📌 [知识点名称]

**名称**：中文名 / English Term
**核心定义**：...
**一句话解释**：...
**常见误区**：...
**考试识别**：在考题中通常以什么形式出现
**关联**：[[相关知识点]]
```

## 双语规则

### 默认模式（中文为主）

- 学科术语、关键词、常见搭配保留英文原文
- "说人话"解释、概念引入、过渡衔接、结构标题用中文
- 逐课讲解：中文叙述为主，术语穿插英文
- Cheat Sheet：全英文

### 全英文模式（用户明确要求时）

- 逐课讲解全部使用英文，用英文"说人话"，叙述流畅自然
- 如果用户提供的课程资料是英文版，术语用词必须完全参考课程资料中的原文，不自行替换或翻译
- Cheat Sheet：全英文（与默认模式一致）
- 用意：培养语言习惯，不同的语言会培养不同的思维习惯

## Cheat Sheet 规则

- **定位**：带入考场的参考材料。用户不需要在考场上现学，所以不需要例子或引入性文字。需要的是知识点、定义、公式、条件、推导步骤
- **语言**：全英文
- **内容**：必须包含所有在逐课讲解中出现过的知识点。每个知识点至少包含：定义、核心公式（如有）、条件/限制、与相关知识点关系。对于用户指定为不重要的部分，可以保留但标注为次要
- **结构**：对应逐课讲解章节顺序，每个知识点用可删减单元（知识点卡片、分点列表）组织，结构清晰便于查找和逐条删除
- **格式**：Markdown，适配 Obsidian 查看
- **不做的事**：不展开例子、不讲故事、不做类比推导。这些在逐课讲解中完成

## 输出结构

```
{课程名}-{日期}/
  课程材料记录.md       （推荐生成，记录排除/重点范围）
  复习脉络.md
  复习首页.md
  第01课-{主题}.md
  第02课-{主题}.md
  ...
  第N课-{主题}.md
  Cheat Sheet.md
  Cheat Sheet.tex    （用户要求转 LaTeX 后生成，可选）
```

用户明确要求后追加：考试、答题卡、详细答案、练习题集。

## 复习首页模板

```markdown
# 复习首页

## 复习范围

- 课程名称：
- 覆盖章节：
- 考试日期：
- 不重要的部分（由用户指定）：

## 推荐学习顺序

### 第一步：逐课讲解（建立概念）
按顺序阅读逐课讲解，用中文+英文术语快速了解每章内容：

1. [[第01课-主题]]
2. [[第02课-主题]]
...

> 逐课讲解用中文"说人话"，夹杂英文术语，适合快速建立概念框架。

### 第二步：Cheat Sheet（考场参考）
逐课讲解读完后，用 [[Cheat Sheet]] 作为考场参考材料。确认理解的内容可以从中删除，最终精简版带入考场。

> Cheat Sheet 是全英文、只包含知识点和公式的参考材料，不展开例子或引入。

## 辅助文件
- [[复习脉络]] — 复习顺序、难度标注、考试重点预判
- [[课程材料记录]] — 材料范围与排除/重点说明
```

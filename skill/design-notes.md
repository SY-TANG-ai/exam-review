# exam-review 设计决策记录

本文件存放 exam-review skill 的所有设计决策，供迭代时参考。不在 SKILL.md 中保留决策状态，只留执行指令。

## 已确认决策（12项）

1. 仅全量生成，不设逐课反馈模式
2. 知识点以 📌 内嵌卡片附属于课节，不生成独立文件
3. 术语随课处理，不生成独立中英术语对照表
4. 首遍默认只产出复习内容，考试/练习由用户明确要求后追加
5. 不设每课 feedback callout，学习过程记录方式待实践确定
6. 学习顺序：逐课讲解 → Cheat Sheet → 考试
7. 逐课讲解是第一阅读材料：帮用户建立概念理解，中文+英文术语"说人话"，每章开头有「本章概览」，必须覆盖所有知识点不遗漏
8. Cheat Sheet 是第二阅读材料：带入考场的参考材料，不是精简版速查表。不需要例子/引入，只收知识点、定义、公式、条件、推导步骤。内容来自逐课讲解，确保不遗漏。逐课讲解负责完整覆盖，Cheat Sheet 负责结构化收录
9. 逐课讲解与 Cheat Sheet 的关系：逐课讲解负责"完整覆盖所有知识点"，Cheat Sheet 负责"所有知识点以可删结构呈现"。信息链是逐课讲解→Cheat Sheet，逐课讲解不能遗漏否则 Cheat Sheet 也会遗漏
10. 双语策略：术语层英文，解释层中文
11. 对于允许携带 Cheat Sheet 的科目，Cheat Sheet 是复习流程核心环节
12. 讲解内容与 Cheat Sheet 结构对应，便于交叉参考
13. 灵活覆盖机制：用户可指定"不重要的部分"（如 case study）或"重要的部分"，agent 记录到材料记录并在讲解/脉络中标注。不重要的部分保留知识点本身但不展开推导或例子，确保 Cheat Sheet 不遗漏知识点
14. 内容范围配置：首遍内容支持用户指定覆盖范围（如某几个 lecture/hw），也支持用户指定排除范围（如某部分 case study）

## 待通过实践确定（5项）

- 学习过程记录：如何记录学会了什么、没学懂什么、需要巩固什么
- Cheat Sheet 格式与流程：首版 Markdown → 后续可能 LaTeX 转 PDF
- 灵活与固定的边界：哪些用户配置 / 哪些自动调整 / 哪些通用（首遍内容范围已确认：用户可指定覆盖范围和排除范围）
- 考试题型偏好：不同科目的计算/概念/编程/设计差异
- 媒体/图片处理：图解、截图的需求和处理方式
